# Library Utilities Overview

This document describes the utility modules in `src/lib/`.

## Categories
- **Performance** — debounce, throttle, memoize, lazy loading
- **Blog** — reading time, TOC, slugs, search
- **A11y** — focus trap, contrast checker, skip link
- **DX** — env validation, logger, constants, error types
- **SEO** — sitemap, JSON-LD, meta tags, canonical URLs
